# 校园悬赏平台 · Sprint 2 实现计划（服务双模式 + 社区 + 私信 + 治理 + 部署）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Sprint 1 的交易内核之上，补齐第二种交易模式（学生挂牌服务 → 他学生下单），并完成社区交流、找搭子、私信、搜索、通知、互评、管理员治理与 Docker 打包，形成完整可答辩的平台。

**Architecture:** 复用 Sprint 1 的统一订单模型——服务模式下 `TradeOrder.seller = 帖主`、`buyer = 下单者`，订单状态机（`IN_PROGRESS → CONFIRMING → COMPLETED`）与悬赏完全共用，仅「建立订单」的动作不同（服务靠**下单**直接建单，悬赏靠**接单**转单）。社区、私信、通知、互评各为独立业务域，通过 `NotificationService` 与交易域解耦。图片存本地 `uploads/`，经 `/uploads/**` 静态映射对外。

**Tech Stack:** 承接 Sprint 1（Java 17 · Spring Boot 3.2 · JPA · MySQL · Vue 3 · Element Plus），新增 `spring-boot-starter-websocket`。

**Spec:** `docs/superpowers/specs/2026-10-11-校园悬赏平台-设计.md`　**前序计划:** `docs/superpowers/plans/2026-10-11-sprint1-账户钱包与悬赏交易.md`

## Global Constraints

- 承接 Sprint 1 全部约束（`ApiResponse`、`BizException`、`CurrentUser.id()`、`BigDecimal`、表名 `trade_order`、资金变动必写 `wallet_log`、悲观锁）。
- **不改 Sprint 1 的表结构**：服务模式复用 `trade_post.type=SERVICE` 与 `trade_order`。若需扩展字段，只新增，不改既有列。
- **服务模式资金规则**：挂牌（发布服务帖）**不建订单、不冻结**；**下单时**创建订单并冻结下单者货款；交付后由下单者确认，`WalletService.settle(buyer=下单者, seller=帖主, amount, orderId)`。
- **一帖多单**：服务帖可被多人下单，每个下单生成独立 `TradeOrder`；服务帖**完成后不关帖**（保持 `OPEN`）。仅悬赏帖（`BOUNTY`）在完成/取消时置 `CLOSED`。
- 图片：本地存储到 `uploads/`，文件名 UUID，返回相对路径 `/uploads/<uuid>.<ext>`；限制类型 `jpg/png/gif/webp`，单文件 ≤ 5MB。
- 新表统一命名 `t_post` / `t_comment` / `post_like` / `t_message` / `t_notification` / `t_review` / `t_report`。
- 管理员：`user.role = 'ADMIN'`；启动时若不存在则初始化一个 `admin/admin123`（仅本地演示用）。
- 前端新增路由 `/market` `/market/:id` `/community` `/pals` `/chat` `/search` `/notify` `/profile`；导航栏补齐入口。

```java
    @Transactional
    public TradeOrder buy(Long postId, Long buyerId) {
        TradePost post = postRepository.findById(postId).orElseThrow(() -> new BizException("服务不存在"));
        if (post.getType() != PostType.SERVICE) throw new BizException("该帖不是服务");
        if (post.getStatus() != PostStatus.OPEN) throw new BizException("该服务已下架");
        if (post.getPublisherId().equals(buyerId)) throw new BizException("不能购买自己的服务");

        TradeOrder o = new TradeOrder();
        o.setPostId(postId); o.setBuyerId(buyerId); o.setSellerId(post.getPublisherId());
        o.setAmount(post.getPrice()); o.setStatus(OrderStatus.IN_PROGRESS);
        orderRepository.save(o);

        walletService.freeze(buyerId, post.getPrice(), o.getId());
        return o;
    }
```

```java
package com.campus.bounty.common;
import org.springframework.stereotype.Service; import org.springframework.web.multipart.MultipartFile;
import java.io.IOException; import java.nio.file.*; import java.util.Set; import java.util.UUID;
@Service
public class FileStorageService {
    private static final Set<String> ALLOWED = Set.of("jpg", "jpeg", "png", "gif", "webp");
    private final Path dir = Paths.get("uploads");
    public String store(MultipartFile file) {
        if (file == null || file.isEmpty()) throw new BizException("文件为空");
        String name = file.getOriginalFilename() == null ? "" : file.getOriginalFilename();
        String ext = name.contains(".") ? name.substring(name.lastIndexOf('.') + 1).toLowerCase() : "";
        if (!ALLOWED.contains(ext)) throw new BizException("仅支持 jpg/png/gif/webp");
        if (file.getSize() > 5L * 1024 * 1024) throw new BizException("图片不能超过 5MB");
        try {
            Files.createDirectories(dir);
            String filename = UUID.randomUUID() + "." + ext;
            file.transferTo(dir.resolve(filename).toAbsolutePath());
            return "/uploads/" + filename;
        } catch (IOException e) { throw new BizException("图片保存失败"); }
    }
}
```

```java
    @Transactional
    public Comment add(Long postId, Long authorId, String content, Long replyToId) {
        if (content == null || content.isBlank()) throw new BizException("评论不能为空");
        Comment c = new Comment();
        c.setPostId(postId); c.setAuthorId(authorId); c.setContent(content); c.setReplyToId(replyToId);
        return commentRepository.save(c);
    }
    public List<Comment> list(Long postId) { return commentRepository.findByPostIdOrderByIdAsc(postId); }

    @Transactional
    public int toggleLike(Long postId, Long userId) {
        Post p = postRepository.findById(postId).orElseThrow(() -> new BizException("帖子不存在"));
        var existing = likeRepository.findByPostIdAndUserId(postId, userId);
        if (existing.isPresent()) { likeRepository.delete(existing.get()); p.setLikeCount(p.getLikeCount() - 1); }
        else { PostLike l = new PostLike(); l.setPostId(postId); l.setUserId(userId); likeRepository.save(l); p.setLikeCount(p.getLikeCount() + 1); }
        postRepository.save(p);
        return p.getLikeCount();
    }
}
```

```java
package com.campus.bounty.message;
import com.fasterxml.jackson.databind.ObjectMapper;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component; import org.springframework.web.socket.*; import org.springframework.web.socket.handler.TextWebSocketHandler;
import java.util.Map; import java.util.concurrent.ConcurrentHashMap;
@Component @RequiredArgsConstructor
public class ChatWebSocketHandler extends TextWebSocketHandler {
    private final ChatService chatService;
    private final ObjectMapper mapper = new ObjectMapper();
    private final Map<Long, WebSocketSession> online = new ConcurrentHashMap<>();

    @Override public void afterConnectionEstablished(WebSocketSession s) {
        online.put((Long) s.getAttributes().get("userId"), s);
    }
    @Override protected void handleTextMessage(WebSocketSession s, TextMessage msg) throws Exception {
        Long fromId = (Long) s.getAttributes().get("userId");
        var node = mapper.readTree(msg.getPayload());
        Long toId = node.get("toId").asLong();
        String content = node.get("content").asText();
        Message saved = chatService.save(fromId, toId, content);
        WebSocketSession target = online.get(toId);
        if (target != null && target.isOpen())
            target.sendMessage(new TextMessage(mapper.writeValueAsString(Map.of(
                "fromId", fromId, "content", content, "id", saved.getId()))));
    }
    @Override public void afterConnectionClosed(WebSocketSession s, CloseStatus st) { online.remove((Long) s.getAttributes().get("userId")); }
}
```
