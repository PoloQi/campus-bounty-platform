# 校园悬赏平台 · Sprint 3 实现计划（管理保障与平台运营）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改动 S1/S2 已定学生侧功能的前提下，交付「管理保障」子系统——纠纷申诉与二选一仲裁、举报处理闭环、全量订单视图与时间线、资金托管监管与冻结总额核对、ECharts 数据看板、封禁/解封、管理员审计日志，以及独立 `/admin` 管理后台。

**Architecture:** 前后端分离，沿用 S1/S2 的 Spring Boot 单体分层。后端在既有 `admin` / `trade` / `wallet` 包内做加法：新增 `Appeal` 聚合与 `AuditLogService`、`AdminQueryService`、`DashboardService`；**仲裁不新写一分钱逻辑**——判收款方胜复用 `WalletService.settle()`、判出资方胜复用 `unfreeze()`（仅以「加法重载」补 remark 参数，旧签名委托新签名，S1/S2 调用零改动）；**不改动 `TradeOrderService` 的任何流转代码**——`DISPUTED` 不在 accept/deliver/confirm/cancel 的状态白名单内，挂起行为由既有校验天然实现。学生举报接口由 `POST /api/admin/reports` 迁至 `POST /api/reports`（S3 对 S2 的唯一微调）。前端新增独立 `AdminLayout` 与 7 个管理页，学生端仅在订单详情加申诉/撤回、在内容页加举报弹窗。

**Tech Stack:** 沿用 Java 17 · Spring Boot 3.2.5 · Spring Data JPA · MySQL 8 · JWT(jjwt 0.12.3) · Lombok · Vue 3 · Pinia · Element Plus · Axios；本 Sprint 新增 **ECharts ^5.5.0**（仅仪表盘一个页面使用）。

**Spec:** `docs/superpowers/specs/2026-10-11-管理保障模块-设计.md`（补充篇，下称「补充篇」）；主规格 `docs/superpowers/specs/2026-10-11-校园悬赏平台-设计.md`；前序计划 `2026-10-11-sprint1-账户钱包与悬赏交易.md`、`2026-10-11-sprint2-服务社区与部署.md`。

## Global Constraints

- 承接 Sprint 1/2 的全部约束：包根 `com.campus.bounty`；统一响应 `ApiResponse<T>`；业务错误抛 `BizException`；时间 `LocalDateTime`；金额 `BigDecimal` + `DECIMAL(10,2)`；JWT 无状态；`@SpringBootTest` 集成测试风格（测试依赖本地 docker MySQL，与 S1/S2 一致）。
- 新表只加两张：`t_appeal`、`t_admin_log`；`t_report` 以 `ddl-auto=update` **只加列不改列**。表名沿用 t_ 前缀约定。
- `OrderStatus.DISPUTED` 在 S1 Task 2 已预留枚举值；**禁止修改枚举本身**，只新增行为。
- **资金红线**：禁止新增任何资金原语；禁止出现直接读写 `wallet` 的管理代码；仲裁只能调用 `WalletService.settle/unfreeze`；不提供后台充值/扣减/调账接口。
- **管理写操作三要素**：① 入口受 `/api/admin/**` 的 `hasRole('ADMIN')` 保护，服务层保留 `requireAdmin` 兜底；② 必须经 `AuditLogService.record(...)` 落 `t_admin_log`；③ 处置结果必须经 `NotificationService.push(...)` 通知当事人。
- 权限收口：`/api/admin/**` 仅 ADMIN；学生举报走 `POST /api/reports`（登录即可）。学生只能对自己作为 buyer/seller 的订单申诉，只能撤回自己的申诉。
- 返回用户信息时用 Map 组装简要字段（id/nickname/status/role），**禁止把含 `passwordHash` 的 User 实体直接序列化给前端**。
- 前端管理页路由统一挂 `/admin` 子树，守卫校验 `localStorage.role === 'ADMIN'`；管理端表格课程规模返回**全量列表 + el-pagination 前端分页**，不做后端分页。
- 注释只写「为什么」；每个 Task 结束要可截图/可演示（课程交付物要求，同 S1/S2）。

## Review Focus

以下五类故障 spec 没有逐句展开、但最容易在实现中被破坏，每条的回归测试已挂到所属 Task：

1. **DISPUTED 挂起被绕过**：订单进入 DISPUTED 后，S1/S2 的 accept/deliver/confirm/cancel 四个接口必须全部抛 `BizException`（依赖既有状态白名单，无显式测试则极易在重构中回归）。→ Task 3 测试 `disputed_orders_block_all_normal_flows`。
2. **仲裁破坏资金守恒**：release/refund 两条仲裁路径跑完，`frozen-summary` 的差额必须仍为 0（仲裁复用 settle/unfreeze 的核心论证靠测试钉死）。→ Task 4 测试 + Task 7 核对测试 + Task 12 全量回归。
3. **封禁不即时生效**：用户被封禁后，其已签发且未过期的 JWT 必须立即不能调用任何受保护接口（`JwtAuthFilter` 查库见到 BANNED 不写 SecurityContext）。→ Task 1 测试 `banned_token_is_rejected`。
4. **举报动作与对象类型错配**：对 `targetType=POST` 的举报传 `CLOSE_TRADE_POST`、对 `TRADE_POST` 传 `DELETE_POST` 等错配必须被后端拒绝，不能静默成功或把错误对象置 DELETED。→ Task 5 测试 `handle_rejects_action_target_mismatch`。
5. **管理接口泄露密码哈希**：订单详情时间线、用户列表组装的用户摘要若直接返回 `User` 实体，`passwordHash` 会随 JSON 下发。→ Task 6 测试 `detail_timeline_has_no_password_hash`。

```java
package com.campus.bounty.admin;
import com.campus.bounty.user.UserRepository;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.test.web.client.TestRestTemplate;
import org.springframework.boot.test.web.server.LocalServerPort;
import org.springframework.http.*;
import java.util.Map;
import static org.junit.jupiter.api.Assertions.*;
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
class AdminAccessSecurityTest {
    @LocalServerPort int port;
    @Autowired TestRestTemplate rest;
    @Autowired UserRepository userRepository;
    @Autowired AdminService adminService;

    private String url(String p) { return "http://localhost:" + port + p; }
    private HttpEntity<?> bearer(String token) {
        var h = new HttpHeaders(); h.setBearerAuth(token); return new HttpEntity<>(h);
    }
    private String login(String username, String password) {
        String body = rest.postForObject(url("/api/auth/login"),
                Map.of("username", username, "password", password), String.class);
        int i = body.indexOf("\"token\":\"") + 9;
        return body.substring(i, body.indexOf("\"", i));
    }
    private void register(String username) {
        rest.postForObject(url("/api/auth/register"),
                Map.of("username", username, "password", "123456", "nickname", username), String.class);
    }

    @Test
    void student_forbidden_admin_api() {
        register("stu_sec_1");
        var resp = rest.exchange(url("/api/admin/reports"), HttpMethod.GET,
                bearer(login("stu_sec_1", "123456")), String.class);
        assertEquals(HttpStatus.FORBIDDEN, resp.getStatusCode());
    }

    @Test
    void admin_allowed_and_login_returns_role() {
        String body = rest.postForObject(url("/api/auth/login"),
                Map.of("username", "admin", "password", "admin123"), String.class);
        assertTrue(body.contains("\"role\":\"ADMIN\""));
        var resp = rest.exchange(url("/api/admin/reports"), HttpMethod.GET,
                bearer(login("admin", "admin123")), String.class);
        assertEquals(HttpStatus.OK, resp.getStatusCode());
    }

    @Test
    void student_report_path_is_open_and_banned_token_is_rejected() {
        register("stu_sec_2");
        String token = login("stu_sec_2", "123456");
        // 学生举报走新路径
        var report = rest.postForEntity(url("/api/reports"),
                bearer0(token, Map.of("targetType", "USER", "targetId", 1, "reason", "测试举报")), String.class);
        assertEquals(HttpStatus.OK, report.getStatusCode());
        // 封禁后同一 token 立即失效
        Long uid = userRepository.findByUsername("stu_sec_2").orElseThrow().getId();
        Long adminId = userRepository.findByUsername("admin").orElseThrow().getId();
        adminService.banUser(adminId, uid);
        var afterBan = rest.exchange(url("/api/trade/posts"), HttpMethod.GET, bearer(token), String.class);
        assertEquals(HttpStatus.FORBIDDEN, afterBan.getStatusCode());
    }

    private HttpEntity<?> bearer0(String token, Object body) {
        var h = new HttpHeaders(); h.setBearerAuth(token);
        h.setContentType(MediaType.APPLICATION_JSON);
        return new HttpEntity<>(body, h);
    }
}
```

```javascript
import { login as apiLogin } from '../api/auth'
export const useUserStore = defineStore('user', {
  state: () => ({

    userId: Number(localStorage.getItem('userId')) || null,

    logout() { this.token = ''; this.userId = null; this.nickname = ''; this.role = 'STUDENT'; localStorage.clear() }

})
```

```java
package com.campus.bounty.trade;
import com.campus.bounty.common.BizException;
import com.campus.bounty.notification.NotificationService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.time.LocalDateTime;
@Service @RequiredArgsConstructor
public class AppealService {
    private final AppealRepository appealRepository;
    private final TradeOrderRepository orderRepository;
    private final NotificationService notificationService;

    @Transactional
    public Appeal open(Long orderId, Long appellantId, String reason) {
        if (reason == null || reason.isBlank()) throw new BizException("申诉理由不能为空");
        if (reason.length() > 500) throw new BizException("申诉理由不超过 500 字");
        TradeOrder o = orderRepository.findByIdForUpdate(orderId).orElseThrow(() -> new BizException("订单不存在"));
        if (o.getStatus() != OrderStatus.IN_PROGRESS && o.getStatus() != OrderStatus.CONFIRMING)
            throw new BizException("当前订单状态不允许申诉");
        if (!appellantId.equals(o.getBuyerId()) && !appellantId.equals(o.getSellerId()))
            throw new BizException("只有订单交易双方可以申诉");
        if (appealRepository.findByOrderIdAndStatus(orderId, "OPEN").isPresent())
            throw new BizException("该订单已有进行中的申诉");
        Appeal a = new Appeal();
        a.setOrderId(orderId); a.setAppellantId(appellantId); a.setReason(reason);
        a.setFromStatus(o.getStatus().name());
        appealRepository.save(a);
        o.setStatus(OrderStatus.DISPUTED);
        o.setUpdatedAt(LocalDateTime.now());
        orderRepository.save(o);
        notificationService.push(otherParty(o, appellantId), "APPEAL_CREATED",
                "对方已就订单 #" + orderId + " 发起申诉，订单暂停处理", orderId);
        return a;
    }

    @Transactional
    public Appeal withdraw(Long appealId, Long operatorId) {
        Appeal a = appealRepository.findById(appealId).orElseThrow(() -> new BizException("申诉不存在"));
        if (!"OPEN".equals(a.getStatus())) throw new BizException("申诉已结束，不能撤回");
        if (!a.getAppellantId().equals(operatorId)) throw new BizException("只能撤回自己的申诉");
        TradeOrder o = orderRepository.findByIdForUpdate(a.getOrderId()).orElseThrow(() -> new BizException("订单不存在"));
        if (o.getStatus() != OrderStatus.DISPUTED) throw new BizException("订单当前不在纠纷中");
        o.setStatus(OrderStatus.valueOf(a.getFromStatus()));
        o.setUpdatedAt(LocalDateTime.now());
        orderRepository.save(o);
        a.setStatus("WITHDRAWN");
        a.setHandledAt(LocalDateTime.now());
        appealRepository.save(a);
        notificationService.push(otherParty(o, operatorId), "APPEAL_WITHDRAWN",
                "对方已撤回订单 #" + o.getId() + " 的申诉", o.getId());
        return a;
    }

    /** 学生端订单详情查询本订单 OPEN 申诉；非交易双方拒绝；无 OPEN 返回 null */
    public Appeal viewOpen(Long orderId, Long viewerId) {
        TradeOrder o = orderRepository.findById(orderId).orElseThrow(() -> new BizException("订单不存在"));
        if (!viewerId.equals(o.getBuyerId()) && !viewerId.equals(o.getSellerId()))
            throw new BizException("无权查看该订单申诉");
        return appealRepository.findByOrderIdAndStatus(orderId, "OPEN").orElse(null);
    }

    private Long otherParty(TradeOrder o, Long me) {
        return me.equals(o.getBuyerId()) ? o.getSellerId() : o.getBuyerId();
    }
}
```

```java
    @Transactional
    public void unfreeze(Long userId, BigDecimal amount, Long orderId, String remark) {
        Wallet w = lock(userId);
        if (w.getFrozen().compareTo(amount) < 0) throw new BizException("冻结金额异常，无法解冻");
        w.setFrozen(w.getFrozen().subtract(amount));
        w.setBalance(w.getBalance().add(amount));
        Wallet saved = walletRepository.save(w);
        walletLogRepository.save(WalletLog.of(userId, "UNFREEZE", amount, saved.getBalance(), orderId, remark));
    }
    @Transactional
    public void unfreeze(Long userId, BigDecimal amount, Long orderId) {
        unfreeze(userId, amount, orderId, "取消解冻退回");
    }

    @Transactional
    public void settle(Long buyerId, Long sellerId, BigDecimal amount, Long orderId, String payRemark, String incomeRemark) {
        Wallet buyer = lock(buyerId);
        if (buyer.getFrozen().compareTo(amount) < 0) throw new BizException("冻结金额异常，无法结算");
        buyer.setFrozen(buyer.getFrozen().subtract(amount));
        walletRepository.save(buyer);
        walletLogRepository.save(WalletLog.of(buyerId, "PAY", amount.negate(), buyer.getBalance(), orderId, payRemark));

        Wallet seller = lock(sellerId);
        seller.setBalance(seller.getBalance().add(amount));
        walletRepository.save(seller);
        walletLogRepository.save(WalletLog.of(sellerId, "INCOME", amount, seller.getBalance(), orderId, incomeRemark));
    }
    @Transactional
    public void settle(Long buyerId, Long sellerId, BigDecimal amount, Long orderId) {
        settle(buyerId, sellerId, amount, orderId, "悬赏支出", "接单收入");
    }
```

```java
    private Appeal resolve(Long adminId, Long appealId, String comment, boolean paySeller) {
        adminService.requireAdmin(adminId);
        if (comment == null || comment.isBlank()) throw new BizException("处理意见不能为空");
        if (comment.length() > 500) throw new BizException("处理意见不超过 500 字");
        Appeal a = appealRepository.findById(appealId).orElseThrow(() -> new BizException("申诉不存在"));
        if (!"OPEN".equals(a.getStatus())) throw new BizException("申诉已结束，不能重复裁决");
        TradeOrder o = orderRepository.findByIdForUpdate(a.getOrderId()).orElseThrow(() -> new BizException("订单不存在"));
        if (o.getStatus() != OrderStatus.DISPUTED) throw new BizException("订单当前不在纠纷中");

        if (paySeller) {
            walletService.settle(o.getBuyerId(), o.getSellerId(), o.getAmount(), o.getId(), "仲裁打款", "仲裁打款");
            o.setStatus(OrderStatus.COMPLETED);
            a.setOutcome("RELEASE_TO_SELLER");
            auditLogService.record(adminId, AuditLogService.APPEAL_RELEASE, "ORDER", o.getId(), "仲裁打款 ¥" + o.getAmount() + "：" + comment);
        } else {
            walletService.unfreeze(o.getBuyerId(), o.getAmount(), o.getId(), "仲裁退款");
            o.setStatus(OrderStatus.CANCELLED);
            a.setOutcome("REFUND_TO_BUYER");
            auditLogService.record(adminId, AuditLogService.APPEAL_REFUND, "ORDER", o.getId(), "仲裁退款 ¥" + o.getAmount() + "：" + comment);
        }
        o.setUpdatedAt(LocalDateTime.now());
        orderRepository.save(o);
        closeBountyPost(o);

        a.setStatus("RESOLVED");
        a.setAdminId(adminId);
        a.setAdminComment(comment);
        a.setHandledAt(LocalDateTime.now());
        appealRepository.save(a);

        String text = paySeller ? "申诉已裁决：款项支付给收款方" : "申诉已裁决：款项退回出资方";
        notificationService.push(o.getBuyerId(), "APPEAL_RESOLVED", text + "（订单 #" + o.getId() + "）", o.getId());
        if (o.getSellerId() != null)
            notificationService.push(o.getSellerId(), "APPEAL_RESOLVED", text + "（订单 #" + o.getId() + "）", o.getId());
        return a;
    }

    /** 与 S2 Task 3 同一规则：仅 BOUNTY 终态关帖，SERVICE 一帖多单保持 OPEN */

            if (p.getType() == PostType.BOUNTY) {
                p.setStatus(PostStatus.CLOSED);
                postRepository.save(p);
            }
```

```java
                result = "VALID";
            }
            case "CLOSE_TRADE_POST" -> {
                if (!"TRADE_POST".equals(r.getTargetType())) throw new BizException("动作与举报对象类型不匹配");
                closeTradePost(adminId, r.getTargetId());
                result = "VALID";
            }
            case "BAN_USER" -> {
                Long bannedId = switch (r.getTargetType()) {
                    case "USER" -> r.getTargetId();
                    case "POST" -> postRepository.findById(r.getTargetId())
                            .orElseThrow(() -> new BizException("帖子不存在")).getAuthorId();
                    case "TRADE_POST" -> tradePostRepository.findById(r.getTargetId())
                            .orElseThrow(() -> new BizException("悬赏不存在")).getPublisherId();
                    default -> throw new BizException("未知举报对象类型");
                };
                banUser(adminId, bannedId);
                result = "VALID";
            }
            default -> throw new BizException("不支持的处理动作");
        }
        r.setStatus("HANDLED");
        r.setResult(result);
        r.setHandlerId(adminId);
        r.setHandleComment(comment);
        r.setHandledAt(java.time.LocalDateTime.now());
        reportRepository.save(r);
        auditLogService.record(adminId, AuditLogService.HANDLE_REPORT, "REPORT", reportId, action + "：" + comment);
        String text = "VALID".equals(result) ? "举报成立，已处置（" + action + "）" : "举报经核实驳回";
        notificationService.push(r.getReporterId(), "REPORT_HANDLED",
                "你对 " + r.getTargetType() + "#" + r.getTargetId() + " 的举报" + text, reportId);
```

```java
package com.campus.bounty.admin;
import com.campus.bounty.trade.OrderStatus; import com.campus.bounty.trade.TradeOrderRepository;
import com.campus.bounty.user.UserRepository;
import com.campus.bounty.wallet.WalletRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import java.math.BigDecimal; import java.time.LocalDate; import java.time.LocalDateTime;
import java.util.*;
@Service @RequiredArgsConstructor
public class DashboardService {
    private final UserRepository userRepository;
    private final TradeOrderRepository orderRepository;
    private final WalletRepository walletRepository;
    private final ReportRepository reportRepository;
    private final AppealRepository appealRepository;
    private final AdminService adminService;

    public Map<String, Object> dashboard(Long adminId) {
        adminService.requireAdmin(adminId);
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("userCount", userRepository.count());
        m.put("orderCount", orderRepository.count());
        m.put("completedCount", orderRepository.countByStatus(OrderStatus.COMPLETED));
        m.put("gmv", orderRepository.sumCompletedAmount());
        m.put("frozenTotal", walletRepository.sumFrozen());
        m.put("pendingReports", reportRepository.countByStatus("PENDING"));
        m.put("openAppeals", appealRepository.countByStatus("OPEN"));

        Map<String, Long> dist = new LinkedHashMap<>();
        for (OrderStatus s : OrderStatus.values()) dist.put(s.name(), 0L);
        for (Object[] row : orderRepository.statusDistribution())
            dist.put(((OrderStatus) row[0]).name(), (Long) row[1]);
        m.put("statusDist", dist.entrySet().stream()
                .map(e -> Map.of("status", e.getKey(), "count", e.getValue())).toList());

        LocalDate today = LocalDate.now();
        LocalDateTime since = today.minusDays(6).atStartOfDay();
        Map<LocalDate, Long> created = toDateMap(orderRepository.dailyCreated(since));
        Map<LocalDate, Long> completed = toDateMap(orderRepository.dailyCompleted(since));
        List<Map<String, Object>> trend = new ArrayList<>();
        for (int i = 0; i < 7; i++) {
            LocalDate d = today.minusDays(6 - i);
            Map<String, Object> point = new LinkedHashMap<>();
            point.put("date", d.toString());
            point.put("created", created.getOrDefault(d, 0L));
            point.put("completed", completed.getOrDefault(d, 0L));
            trend.add(point);
        }
        m.put("trend", trend);
        return m;
    }

    private Map<LocalDate, Long> toDateMap(List<Object[]> rows) {
        Map<LocalDate, Long> map = new HashMap<>();
        for (Object[] row : rows) map.put(((java.sql.Date) row[0]).toLocalDate(), (Long) row[1]);
        return map;
    }
}
```

```java
    public java.util.List<java.util.Map<String, Object>> listUsers(Long adminId, String nickname, String status) {
        requireAdmin(adminId);
        String kw = (nickname == null || nickname.isBlank()) ? null : nickname;
        String st = (status == null || status.isBlank()) ? null : status;
        return userRepository.search(kw, st).stream().map(u -> {
            java.util.Map<String, Object> m = new java.util.LinkedHashMap<>();
            m.put("id", u.getId()); m.put("username", u.getUsername()); m.put("nickname", u.getNickname());
            m.put("role", u.getRole()); m.put("status", u.getStatus()); m.put("createdAt", u.getCreatedAt());
            return m;
        }).toList();
    }

    @Transactional
    public void unbanUser(Long adminId, Long userId) {
        requireAdmin(adminId);
        User u = userRepository.findById(userId).orElseThrow(() -> new BizException("用户不存在"));
        u.setStatus("ACTIVE");
        userRepository.save(u);
        auditLogService.record(adminId, AuditLogService.UNBAN_USER, "USER", userId, "解封用户：" + u.getNickname());
    }
```

```java
        r.setTitle("S3验收单" + buyer); r.setPrice(new BigDecimal(price));

    @Test
    void full_dispute_to_release_chain_conserves_money_and_leaves_audit_trail() {

        var o = inProgressBounty(6601L, 6602L, "20.00");

        appealService.open(o.getId(), 6602L, "我已完成代取，对方想取消赖账");

        assertTrue(notificationService.list(6601L).stream().anyMatch(n -> "APPEAL_RESOLVED".equals(n.getType())));
        assertTrue(notificationService.list(6602L).stream().anyMatch(n -> "APPEAL_RESOLVED".equals(n.getType())));
    }
```
