# 校园悬赏平台 · Sprint 1 实现计划（账户钱包 + 悬赏交易内核）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可运行的"悬赏担保交易"最小闭环——学生注册登录 → 充值 → 发布悬赏（冻结赏金）→ 他人接单 → 交付 → 确认 → 结算打款。

**Architecture:** 前后端分离。后端 Spring Boot 单体，按业务域分包（auth / user / wallet / trade），金额用 `BigDecimal` + 数据库 `DECIMAL(10,2)`，所有资金变动走 `WalletService` 并记流水。资金冻结/结算与订单状态流转放在 `@Transactional` 领域服务内，用数据库悲观锁（`SELECT ... FOR UPDATE`）保证并发安全。前端 Vue 3 SPA，Pinia 管登录态，Axios 拦截器注入 JWT。

**Tech Stack:** Java 17 · Spring Boot 3.2.x · Maven · Spring Data JPA (Hibernate) · MySQL 8 · jjwt 0.12.3 · Lombok · Vue 3 · Vite · Pinia · Vue Router · Element Plus · Axios · Docker Compose

**Spec:** `docs/superpowers/specs/2026-10-11-校园悬赏平台-设计.md`

## Global Constraints

- Java 17，Spring Boot 3.2.x，构建工具 Maven。
- 包名根：`com.campus.bounty`。
- 数据库 MySQL 8，字符集 `utf8mb4`。本地用 `docker-compose.yml` 起 MySQL，不装本机。
- ORM：Spring Data JPA (Hibernate)。**持久层可替换**（如需 MyBatis-Plus 自行替换，接口签名不变）。
- 金额：Java 用 `BigDecimal`，DB 用 `DECIMAL(10,2)`。禁止用 `double`。
- 表名 `order` 是 SQL 保留字——订单表必须命名 `trade_order`。
- **所有资金变动必须写一条 `wallet_log`**，记录变动后余额，禁止裸改 `wallet` 表。
- 密码用 BCrypt 哈希，禁止明文/可逆加密。
- 认证：JWT，无状态。Token 放 `Authorization: Bearer <token>`。
- 所有 REST 接口返回统一结构 `ApiResponse<T>`：`{ code, message, data }`，`code=0` 表示成功。
- 业务错误抛 `BizException`，由全局异常处理器转成 `ApiResponse`，HTTP 200 + 业务 code（便于前端统一处理）。
- 时间字段统一 `LocalDateTime`，DB `DATETIME`。
- 前端开发端口 5173，后端 8080；前端通过 `/api` 代理到后端。
- 交付物是课程报告与答辩材料：**每个 Task 结束要能截图/能演示**，代码注释只写"为什么"，不写"做什么"。

```java
        l.userId = userId; l.type = type; l.amount = amount; l.balanceAfter = balanceAfter;

    }
```

```java
package com.campus.bounty.config;
import com.campus.bounty.common.BizException;
import io.jsonwebtoken.*; import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value; import org.springframework.stereotype.Component;
import javax.crypto.SecretKey; import java.nio.charset.StandardCharsets; import java.util.Date;
@Component
public class JwtUtil {
    private final SecretKey key; private final long expireMillis;
    public JwtUtil(@Value("${jwt.secret}") String secret, @Value("${jwt.expire-minutes}") long minutes) {
        this.key = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
        this.expireMillis = minutes * 60_000;
    }
    public String generate(Long userId, String username) {
        return Jwts.builder().subject(String.valueOf(userId)).claim("username", username)
                .issuedAt(new Date()).expiration(new Date(System.currentTimeMillis() + expireMillis))
                .signWith(key).compact();
    }
    public Long parse(String token) {
        try {
            String sub = Jwts.parser().verifyWith(key).build().parseSignedClaims(token).getPayload().getSubject();
            return Long.valueOf(sub);
        } catch (Exception e) { throw new BizException(40100, "登录已失效，请重新登录"); }
    }
}
```

```java
@Component
public class JwtAuthFilter extends OncePerRequestFilter {
    private final JwtUtil jwtUtil;
    public JwtAuthFilter(JwtUtil jwtUtil) { this.jwtUtil = jwtUtil; }
    @Override protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain)

        if (h != null && h.startsWith("Bearer ")) {

            } catch (Exception ignored) { /* 无效 token 视为未登录 */ }
        }

    }
```

```java
package com.campus.bounty.wallet;
import com.campus.bounty.common.BizException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service; import org.springframework.transaction.annotation.Transactional;
import java.math.BigDecimal; import java.util.List;
@Service @RequiredArgsConstructor
public class WalletService {
    private final WalletRepository walletRepository;
    private final WalletLogRepository walletLogRepository;

    public Wallet getOrCreate(Long userId) {
        return walletRepository.findByUserId(userId).orElseGet(() -> {
            Wallet w = new Wallet(); w.setUserId(userId); return walletRepository.save(w);
        });
    }
    private Wallet lock(Long userId) {
        return walletRepository.lockByUserId(userId)
                .orElseGet(() -> { Wallet w = new Wallet(); w.setUserId(userId); return walletRepository.save(w); });
    }
    @Transactional
    public Wallet recharge(Long userId, BigDecimal amount) {
        if (amount == null || amount.signum() <= 0) throw new BizException("充值金额必须大于 0");
        Wallet w = lock(userId);
        w.setBalance(w.getBalance().add(amount));
        Wallet saved = walletRepository.save(w);
        walletLogRepository.save(WalletLog.of(userId, "RECHARGE", amount, saved.getBalance(), null, "模拟充值"));
        return saved;
    }
    public List<WalletLog> logs(Long userId) { return walletLogRepository.findByUserIdOrderByIdDesc(userId); }
}
```

```java
    @Transactional
    public void freeze(Long userId, BigDecimal amount, Long orderId) {
        Wallet w = lock(userId);
        if (w.getBalance().compareTo(amount) < 0) throw new BizException("余额不足，无法冻结");
        w.setBalance(w.getBalance().subtract(amount));
        w.setFrozen(w.getFrozen().add(amount));
        Wallet saved = walletRepository.save(w);
        walletLogRepository.save(WalletLog.of(userId, "FREEZE", amount.negate(), saved.getBalance(), orderId, "冻结至订单"));
    }

    @Transactional
    public void unfreeze(Long userId, BigDecimal amount, Long orderId) {
        Wallet w = lock(userId);
        if (w.getFrozen().compareTo(amount) < 0) throw new BizException("冻结金额异常，无法解冻");
        w.setFrozen(w.getFrozen().subtract(amount));
        w.setBalance(w.getBalance().add(amount));
        Wallet saved = walletRepository.save(w);
        walletLogRepository.save(WalletLog.of(userId, "UNFREEZE", amount, saved.getBalance(), orderId, "取消解冻退回"));
    }

    @Transactional
    public void settle(Long buyerId, Long sellerId, BigDecimal amount, Long orderId) {
        Wallet buyer = lock(buyerId);
        if (buyer.getFrozen().compareTo(amount) < 0) throw new BizException("冻结金额异常，无法结算");
        buyer.setFrozen(buyer.getFrozen().subtract(amount));
        walletRepository.save(buyer);
        walletLogRepository.save(WalletLog.of(buyerId, "PAY", amount.negate(), buyer.getBalance(), orderId, "悬赏支出"));

        Wallet seller = lock(sellerId);
        seller.setBalance(seller.getBalance().add(amount));
        walletRepository.save(seller);
        walletLogRepository.save(WalletLog.of(sellerId, "INCOME", amount, seller.getBalance(), orderId, "接单收入"));
    }
```

```java
    public TradePost publish(Long publisherId, PublishReq req) {

        post.setTitle(req.getTitle()); post.setDescription(req.getDescription());
```

```java
package com.campus.bounty.trade;
import com.campus.bounty.common.BizException; import com.campus.bounty.wallet.WalletService;
import lombok.RequiredArgsConstructor; import org.springframework.stereotype.Service; import org.springframework.transaction.annotation.Transactional;
import java.time.LocalDateTime;
@Service @RequiredArgsConstructor
public class TradeOrderService {
    private final TradeOrderRepository orderRepository;
    private final TradePostRepository postRepository;
    private final WalletService walletService;

    private TradeOrder locked(Long orderId) {
        return orderRepository.findByIdForUpdate(orderId).orElseThrow(() -> new BizException("订单不存在"));
    }
    @Transactional
    public TradeOrder accept(Long orderId, Long accepterId) {
        TradeOrder o = locked(orderId);
        if (o.getStatus() != OrderStatus.PENDING) throw new BizException("订单状态不允许此操作");
        if (o.getBuyerId().equals(accepterId)) throw new BizException("不能接自己的悬赏");
        o.setSellerId(accepterId);
        o.setStatus(OrderStatus.IN_PROGRESS);
        o.setUpdatedAt(LocalDateTime.now());
        return orderRepository.save(o);
    }
}
```

## 已验证的关键设计（答辩口径）

- **钱守恒**：`freeze` 只把 `balance→frozen`，`settle` 只把 `buyer.frozen→seller.balance`，任一时刻 `Σbalance + Σfrozen` 恒定。Task 6/11 的断言即为证明。
- **统一订单模型**：`TradeOrder.buyerId/sellerId` 表达资金方向，悬赏里 `buyer=publisher`、`seller=accepter`，Sprint 2 的服务模式复用同一张表。
- **并发安全**：资金操作一律先 `findByIdForUpdate` / `lockByUserId` 悲观锁，避免同一订单并发确认导致双重打款。
